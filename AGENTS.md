# module_ccs811 — датчик качества воздуха CCS811

> **Опциональный модуль.** Подключается через `src_filter` (define-флаг `MODULE_CCS811`
> выводится из `src_filter` автоматически через `[registry]`).

Датчик CCS811 (I2C): эквивалентный CO₂ (eCO2) и TVOC. Публикует на ресурсную шину
`core_state` только доступность и значения; веб-страница и терминал — только просмотр.

- **Репозиторий:** https://github.com/Arcanum753/CCS811
- **Папка:** `src/module_ccs811/`
- **Флаг активации:** `MODULE_CCS811` (генерируется в `src/modules_defines.h` из `src_filter`)
- **Registry:** `object=module_ccs811`, `define=MODULE_CCS811`, `namespace=ccs811`,
  `web=1`, `loop=0`, `res=1`
- **Платформы:** ESP8266/ESP32 (тестирование — ESP32)
- **Зависит от ядра:** `core_web`, `core_state`, `core_task`, `core_terminal`
- **Опционально использует:** `module_hdc1080` (компенсация t/RH через шину)

## Назначение

Чтение CCS811 по I2C (`Wire`), автоопределение адреса `0x5A`/`0x5B`, проверка `HW_ID`
(`0x20` == `0x81`), инициализация (`APP_START`, drive mode 1), публикация eCO2/TVOC.

## Функциональные требования

- FR-CCS811-1: Автоопределение адреса и проверка `HW_ID == 0x81`.
- FR-CCS811-2: Инициализация: проверка `APP_VALID`, при необходимости software reset,
  `APP_START`, `MEAS_MODE = 1` (измерение раз в секунду).
- FR-CCS811-3: Публикация `ccs811.available` (BOOL), `ccs811.eco2` (I32, ppm),
  `ccs811.tvoc` (I32, ppb).
- FR-CCS811-4: При `ERROR` — чтение `ERROR_ID`, `available=false`, повторная инициализация
  не чаще раза в 5 с.
- FR-CCS811-5: Компенсация t/RH из `hdc1080.temperature`/`hdc1080.humidity` (если датчик
  доступен) через `ENV_DATA` раз в 60 с.
- FR-CCS811-6: Периодический опрос через `core_task.every("ccs811_poll", …, 1000)`.
- FR-CCS811-7: Веб-страница `ccs811.html` — только показ значений.
- FR-CCS811-8: Терминальная команда `ccs` — статус и значения.

## Аппаратные интерфейсы

| Интерфейс | Выводы по умолчанию | Примечание |
|-----------|---------------------|------------|
| I2C (CCS811) | ESP32 21/22, ESP8266 4/5 (SDA/SCL) | общая шина `Wire`; адрес `0x5A`/`0x5B` |

## Веб-интерфейс

| Метод | URL | Назначение |
|---|---|---|
| GET | `/ccs811/info` | CVT: состояние, адрес, статус, ошибка, показания |
| GET | `/ccs811/read` | CVT: только показания (опрос раз в 1 с) |
| GET | `/ccs811/ver` | версия модуля |

Страница `ccs811.html` (пункт меню — `web/_menu.html`). Полей редактирования нет.

## Ресурсы шины (namespace `ccs811`)

| Ресурс | Тип | Описание |
|---|---|---|
| `ccs811.available` | BOOL ro | чип инициализирован, есть валидные данные, нет ошибки |
| `ccs811.eco2` | I32 ro | эквивалент CO₂, ppm |
| `ccs811.tvoc` | I32 ro | TVOC, ppb |

`<ns>.save` и `<ns>.mode` не регистрируются: у модуля нет сохраняемых настроек.

При потере датчика/ошибке публикуется `available=false` и значения `0`; попытка
переинициализации — не чаще раза в 5 с.

## Терминал

Компонент `module_ccs811`, команда `ccs`, `editable = false`.

| Команда | Назначение |
|---|---|
| `ccs` / `ccs show` | состояние, адрес, статус, eCO2, TVOC |
| `ccs help` | справка |

## Ограничения

- После включения CCS811 требует burn-in ~20–30 минут; первые показания (обычно ~400 ppm)
  недостоверны — это отражено на странице и в `ccs help`.
- Baseline не сохраняется: после перезагрузки датчик снова проходит прогрев.
- Если `module_hdc1080` отсутствует или датчик недоступен, компенсация t/RH не выполняется.
- Модуль не сохраняет ничего на FS: конфига нет.

## Критерии приёмки

- `esp32-i2c-mapper` (или иной env с модулем) собирается.
- Страница `ccs811.html` открывается, значения обновляются.
- `/state/catalog` содержит `ccs811.available|eco2|tvoc` с `rw=false`.
- Команда `ccs` печатает значения; при ошибке — статус с `ERROR_ID`.
